# npenkov/homebrew-tap

Homebrew tap for my apps and tools.

```bash
brew tap npenkov/tap
```

## Casks

### [herdr-menu-bar](https://github.com/npenkov/herdr-menu-bar)

Menu-bar app showing, at a glance, the status of AI agents running in [herdr](https://herdr.dev).

```bash
brew install --cask herdr-menu-bar
```

## Formulae

### [git-substatus](https://github.com/npenkov/git-substatus)

Interactive TUI to view git status across many repos at once.

```bash
brew install git-substatus
```

### [git-worktree-refresh](https://github.com/npenkov/git-worktree-refresh)

```bash
brew install git-worktree-refresh
```
